# 五分钟现场演示脚本

> 面试现场只有一次机会证明「这些仓库不是摆设」。这份脚本把五分钟切成六段，
> 每段都有**动作**（敲什么）、**话术**（说什么）、以及**翻车预案**（如果不行怎么办）。
>
> 核心的一句话：**演示的不是「我的代码能跑」，而是「我的门禁会红，而且红得可复现」。**

---

## 0. 开始之前（前一晚准备，不进五分钟）

| 检查 | 命令 | 预期 |
|---|---|---|
| 依赖还在 | `python -m pytest --collect-only -q \| tail -1` | 见到用例总数 |
| 演示脚本能跑 | `python scripts/demo.py` | 末尾 `✔ 四幕全部按预期` |
| 在线报表能开 | 浏览器开 [Pages 报表](https://lefan17.github.io/perf-baseline-quality-gate/) | 「当前基线」不是空的 |
| 备用：离线看板 | `python platform_cli.py serve --port 8765` | `http://127.0.0.1:8765` |
| 备用：截图 | `docs/images/` 下四张图 | 断网时直接讲图 |

**为什么提前跑一遍而不是现场跑**：演示脚本自己 12 秒跑完，但它会起被测服务、写临时库；
第一次在某台机器上跑可能踩端口或 TMP 目录的坑（本仓踩过，见 `docs/wave*.md`）。
前一晚跑通一次，现场就只是重复。

---

## 1. 第 0:00 – 0:40 · 一句话定位

**敲**：什么都不敲，先把这句话说完。

> 「这是一套性能基线 + 质量门禁平台。它解决的不是『压一次出个报告』，
> 而是『上线前能不能自动判断这次比上次慢了多少』。
> 三件事：自研压测引擎、12 条门禁规则、以及**证明门禁真的会拦住**的测试。」

**为什么这么开场**：绝大多数人做的性能测试是「跑一次、贴张图」。这句话把话题从
「你测了多快」扳到「你怎么知道它变慢了」，后者才是测开岗的核心。

---

## 2. 第 0:40 – 1:30 · 先看结果（报表）

**敲**：浏览器打开 <https://lefan17.github.io/perf-baseline-quality-gate/>

指三处（每处一句话）：

| 指哪里 | 说什么 |
|---|---|
| 运行历史表（10 轮） | 「每轮都有 run_id、P95/P99、RPS、错误率，不是一个数字」 |
| P95 趋势折线 | 「趋势持平，这说明我的容忍带没有把真实波动吃成噪声」 |
| 「当前基线」 | 「基线是显式的：只有 `baseline set` 才写，CI 不会自己批准自己」 |

**翻车预案**：打不开 Pages（现场 Wi-Fi）→ 立刻改用本地看板
`python platform_cli.py serve --port 8765`，或直接切到 `docs/images/dashboard-hero.png`（截图）。

---

## 3. 第 1:30 – 3:00 · 核心：让门禁红给他看（90 秒）

**敲**：

```bash
python scripts/demo.py
```

（完整版约 12 秒；如果只想要「红/绿」两屏，`python scripts/demo.py --duration 1`）

脚本会走四幕，你在每一幕只讲一句：

| 幕 | 屏幕上的东西 | 你说 |
|---|---|---|
| 1/4 跑一轮 | `[PASS] R1…R5`，R3 显示 `[SKIP] 未设置基线` | 「先跑一轮，五条规则全绿。注意 R3 是 SKIP 不是 PASS —— 没有基线时它不假装比过」 |
| 2/4 设基线 | `[baseline] 已把本轮设为基线` | 「基线只能由人显式设。这是刻意的：CI 自动设基线，『慢慢变慢』就会被每一轮自己批准」 |
| 3/4 注入劣化 | `注入后的基线：p95=5.6ms / rps=4129` | 「我把基线改快 10 倍，模拟『上周比现在快得多』。**只改基线，不动被测代码**」 |
| 4/4 重新判定 | `[FAIL] R3-baseline-degradation: 相对基线劣化 5 项…`，`→ 退出码 1` | 「同一个 run 重新判定，红了，退出码 1 —— 流水线会停在这里」 |
| 彩蛋 | 改回基线 → `[PASS] R3`，`退出码 0` | 「改回去就绿了。所以红是**劣化**导致的，不是运气」 |

**这一段的三个杀伤点**（按顺序说，别一次全倒出来）：

1. **有退出码**：「门禁不是打印一行 PASS，它返回非 0，CI 能真的拦住」；
2. **可复现**：「我没再跑一轮压测，而是重新判定同一个 run —— 输入固定，输出必然确定。
   再跑一轮的话，红可能是机器抖动，那我就说不清是门禁work 还是我走运」；
3. **注入的是基线不是代码**：「改被测代码让它变慢，测到的是『改完恰好红了』；
   改基线测到的才是『门禁能拦住劣化』本身」。

**翻车预案**：`demo.py` 报端口占用 → `python scripts/demo.py --workdir %TEMP%\demo`
换个临时目录；还是不行就用 `pytest tests/test_r3_end_to_end.py -v`（同样证明红，慢一些）。

## 4. 第 3:00 – 4:00 · 数字为什么可信（诚实边界）

**敲**：`docs/诚实边界.md`（不用滚动，指标题就够）。

> 「这个仓库最容易被问的是『你的数字准吗』。我写了一份诚实边界，核心是三条：」

| 边界 | 一句话 |
|---|---|
| 绝对值不可外推 | 「同配置在 Windows 上 MySQL 比 SQLite 快 2.72 倍，在 Linux 上反过来慢 1.9 倍。所以你只能从我这里拿走『锁粒度决定排队形态』这一层形状」 |
| 数据量必须接近真实 | 「800 条时 N+1 只慢 2.08 倍，20 000 条时 7.81 倍。用 800 条测出来的结论是错的」 |
| 分位不能混算 | 「混合场景的 P95 不是各场景 P95 的平均，分位数是顺序统计量，必须回原始样本池化重算」 |

**如果被追问「那你的数字还有什么用」**：
> 「有两个用途：一是同一环境下的**趋势对比**（这是门禁的判据）；二是**比例关系**
> （N+1 该改成什么样、加一层代理要付多少）。绝对值我从来不当结论用。」

---

## 5. 第 4:00 – 4:45 · 工程化外壳（30 秒扫过）

**敲**：`git log --oneline -8`（让他看到提交信息是完整的句子）。

> 「工程化这块有四个入口：容器化、覆盖率门槛（per-file，不是平均分）、
> mypy 把脚本也纳进来、以及依赖逐字钉死（`check_deps_sync.py`）。
> 这些不是装饰 —— 每一条都在 CI 里拦过一次我自己。」

**不要展开**：这一段的目的是「让他知道有」，不是「讲完」。展开会被拖进 20 分钟的
工具链讨论，那时你的五分钟已经用完了。

---

## 6. 第 4:45 – 5:00 · 收尾一句 + 交还主动权

> 「这套东西的边界我也清楚：被测系统是我自己写的，真实企业里你不掌握源码；
> 分布式压测只做到多进程，没有跨机器调度。这两条我没打算藏。
> 您想先看哪一块？」

**为什么最后要交还主动权**：面试官问出的下一个问题，一定是他关心的方向；
你准备好的细节往那个方向堆，命中率高得多。反过来，如果你自顾自讲完十分钟，
他只会记住「这人话多」。

## 附 A：五条最可能被追问的问题与一句话答案

| 追问 | 一句话 |
|---|---|
| 你自己写压测引擎，为什么不直接用 Locust？ | 「因为我要能把『失败样本』和『热身样本』分开处理，还要在每 worker 自己的线程里保持 keep-alive；用 Locust 我得改它的插件。写下来 300 行，改它要读 3000 行」 |
| R3 凭什么 10% 容忍带？ | 「实测本机运行间波动 2.27σ，10% 对应单尾假阳性 1.2%。这是工程折中，不是理论值，文档里写了」 |
| 你的门禁在 CI 上真的会红吗？ | 「四条规则里 R1/R2/S1/S3 是阻塞的；R3 在 PR 上带 `--r3-advisory` 只报警（噪声主导），nightly 才阻塞。这个取舍写在 `docs/已知问题.md`」 |
| 覆盖率的 per-file 门槛会误伤吗 | 「会。所以我给了排除清单，理由是『只在外层 uvicorn 子进程执行的模块，父进程结构上到不了』，不是『懒得测』」 |
| 这套东西你一个人做的？ | 「是。所以我把过程也留下来了：issue → 分支 → PR → 自 review，你能看到我改错过什么，比如 `266a1a7` 那次把 `pgrep -f` 写成 `pgrep -f nginx.exe`」 |

## 附 B：如果只能演示 90 秒

```bash
python scripts/demo.py --duration 1
```

只讲第 1/4 幕与第 4/4 幕：

> 「跑一轮全绿 → 我把基线改快 10 倍 → 同一个 run 重新判定变红、退出码 1。
> 门禁不是打印，是能拦住。」

90 秒讲完这一件事，比五分钟讲五件事更让人记住。
